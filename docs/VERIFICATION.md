## 怎么复查

仓库根目录执行 `npm ci --ignore-scripts --legacy-peer-deps`、`npm run build`、`npm run test:unit`。设置 `ASL_CORE_EXECUTABLE` 为完整 ASL App 的核心路径后执行 `npm test`。首次操作步骤见 [安装指南](INSTALLATION.md)。

发布包内的 README 保持发布当时版本；当前仓库文档会继续修正。下载旧版本时，以对应 Release 和当前安装指南核对适用范围，不把文档修订当成运行时代码升级。
